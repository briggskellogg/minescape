# Legacy Bedrock prototype

This directory preserves the Bedrock/Moogul baseline from commit `3858837` for reference only.
It is not installed, launched, or supported by the Java MineScape build at the repository root.

Two immutable Git tags preserve the complete history without mixing obsolete Bedrock code into
the Java rebuild:

- `legacy-bedrock-v0` is the baseline mirrored by this directory.
- `legacy-bedrock-v0-final` is the final Bedrock-only tip. It also contains the Spelljammer
  same-seed test-world manager, the completed autostart notes, and the field-tested invite fix.
