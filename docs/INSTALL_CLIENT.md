# Client installation

V1 requires isolated Family and Parent Steward Fabric game directories that do not modify an unrelated `.minecraft` installation. The profile builder, server resource-pack wiring, and official-Launcher registration are not implemented at this checkpoint; no client profile is ready for family use. They remain release gates rather than installer claims.

All playing clients require Fabric Loader/API, the paired MineScape Client, the approved Matcha resource artifact, and Enhanced Falling Trees only if its release gate passes. Controller devices additionally require Controlify and YACL. Performance/visual mods are replaceable and never world authority.

The first controller calibration is performed with keyboard and mouse unused. Open Pause → Advancements, enable Controlify's virtual mouse on the real advancement screen, and preserve the class/binding Controlify writes. V1 requires an exact-stack test on each real controller: launch and join, survive `/reload` and a server crash/restart, exercise Mortal Hearts including respawn grace, navigate all 64 visible Matcha nodes across From Earth, Through Hell, and To Dreams, and use recipes, crafting, inventory, trading, smithing, text entry, wards, sleep, death, and respawn without keyboard or mouse.

The Parent Steward profile includes OrthoCamera. The mod grants no authority; a separately authenticated MineDeck lease controls Steward/Creative state.

Server resource-pack acceptance will be mandatory at V1. The server resource-pack endpoint and client-profile wiring are not implemented yet. A later Matcha visual candidate may be admitted only as a tested resource-only derivative with no `data/**`, with a proven rollback to the frozen 1.02 asset hash.
