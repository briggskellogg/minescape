# Operations

## Daily use

- **Launch MineScape & MineDeck** starts or attaches to MineDeck, starts MineScape only if needed, waits for a real protocol response, and opens the dashboard.
- **Play MineScape** performs the same safe startup and opens the official Launcher. One final supported Launcher/Quick Play click may be required.
- Green means a valid Minecraft Server List Ping, not merely a Java process.
- Closing the browser dashboard leaves MineDeck and the server running in the tray.

## Players

Keep the whitelist enabled. An unknown authenticated join creates a short-lived pending request. Approve the UUID and role in MineDeck. First join uses the single public starter-village spawn and an empty ordinary inventory. MineDeck never assigns homes, kits, claims, private wards, or personal spawn points.

## Parent administration

The parent's Minecraft account is ordinary Survival in Family Play. Process, backups, whitelist, fog, wards, characters, and MineJammer are administered out of game. Production Creative requires a recent recovery point, reauthentication, written reason, hard expiry, and a visible Steward indicator. It never applies to a child UUID.

## Backups

Use MineDeck so saves, worlds, dimensions, first-party state, Ledger, fog, and databases share a consistent epoch. Name important milestones. Test-restore backups into MineJammer; never inspect a production backup by booting it as production.
